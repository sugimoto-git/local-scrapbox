# Local Scrapbox

Scrapboxのカード一覧と行単位の編集体験を参考にしたノートアプリです。普段はMacだけで動かす1人用で、パスワードを設定すればサーバーにも置けます。Node.jsの標準機能だけで動作し、追加パッケージや外部サービスは必要ありません。

## Macアプリとして使う

ターミナルで次を1回実行すると、Macのアプリになります（更新したときも同じコマンドです）。

```sh
bash ~/Documents/開発/local-scrapbox/macos/install.sh
```

- **専用ウインドウのアプリ**：「Local Scrapbox.app」がアプリケーションフォルダに入ります。Dock・Launchpad・Spotlightから開けます（インストール時にDockへの追加も選べます）。
- **常駐**：ログインすると裏で自動起動して待機しているので、アプリはすぐ開きます。
- **メモはファイル**：`~/Documents/scrapbox` に、1ページ1つの `.txt` ファイルとして保存されます。ファイル名がタイトル、中身が本文です。テキストエディットなどほかのアプリで編集・作成・名前変更・削除しても、アプリ側に反映されます（削除はゴミ箱へ）。2つ目以降のプロジェクトはサブフォルダになります。
- **メニュー**：⌘N で新規ページ、⇧⌘O でメモのフォルダを開く、⇧⌘B（または上部の「↗」ボタン）で今のページをふだん使いのブラウザで開く。ページメニューの「Finderで表示」でそのページのファイルを表示します。
- 編集履歴・ゴミ箱・設定は `~/Library/Application Support/Local Scrapbox/data` に、画像は `~/Documents/scrapbox/.images` に保存されます。
- 専用ウインドウ版のビルドには Xcode のコマンドラインツール（`xcode-select --install`）が必要です。無い場合は、ブラウザのウインドウで開く版になります。
- 初回は macOS が「node が書類フォルダにアクセスしようとしています」と確認することがあります。「許可」を押してください。
- やめるとき：`bash ~/Documents/開発/local-scrapbox/macos/uninstall.sh`（メモと履歴は消しません）。

`起動.command` をダブルクリックしても、アプリを開きます（まだ入っていなければインストールから始めます）。

ターミナルから一時的に起動する場合は `npm start`（http://127.0.0.1:3210、この場合はメモをファイルにせず `data/` に保存）。Node.js 22.13以降が必要です。

## 使い方

- 右上の「＋」から作成。本文の行をクリックすると編集できます。
- 編集している行は記法を表示し、離れた行は整形して表示します。
- 編集中も、字下げした行は表示と同じ位置・同じ高さのまま編集できます（字下げの空白は見えない幅として扱います）。
- 行の途中にある半角・全角スペースは、編集中だけ薄いドットで表示します（字下げ部分には出しません）。保存・コピーする本文にはドットを含めません。
- `[ページ名]` と `#タグ` でページをつなぎます。未作成リンクからも書き始められます。ページ名は大文字小文字と空白/アンダースコアの違いを区別しません（`[Foo Bar]` と `[foo_bar]` は同じページ）。
- ページ下部に、リンク元・リンク先・同じリンクを持つ関連ページが表示されます。
- タイトルを変えると、既存ページのリンクとタグも更新します。
- 角括弧内で既存タイトルを補完。`#` の後ろでもタグを補完でき、Tabで確定します。
- 選択した文字列に `[` を入力するとリンクになります。
- 画像は、編集中の行のカーソル位置に貼り付け・ドロップできます（字下げした行に貼れば、そのまま字下げされます）。
- `[` の入力で閉じ括弧も補完します。選択文字を⌘/Ctrl+Bで太字にできます。
- Tab/Shift+Tabでインデント、Enterで改行、↑↓で行の移動。
- Option/Alt+↑↓は、その行と、続く深いインデントの行をまとめて移動します。
- 複数行の選択：Shift+↑↓、行をまたぐドラッグ、⌘/Ctrl+A（2回目で全行）。選択中は、コピー・切り取り・貼り付け・Delete・Tab/Shift+Tab・Option/Alt+↑↓で行をまとめて操作できます。
- 複数行の貼り付け、取り消しとやり直し、全文ソース編集に対応。
- 行にカーソルを合わせると出る「¶」で、その行へのリンク（`#/page/タイトル#L行番号`）をコピーできます。開くと該当行が光ります。`[ページ名#L3]` のようにページ内から行へリンクすることもできます。行番号は本文の先頭行を1とする番号で、行の追加・削除でずれます。
- ページメニューから、ピン止め、複製、履歴復元、リンクのコピー、テキストの書き出し、削除ができます。編集履歴は、その編集で変わった行を差分で表示します。
- 左上のメニューから、プロジェクトの切り替え・作成、JSON入出力、ゴミ箱、プロジェクト設定が開けます。
- ゴミ箱では、復元のほか、1ページずつの完全削除と「ゴミ箱を空にする」ができます（どちらも2回押して確定）。
- 検索はタイトルと本文が対象で、スペース区切りのAND検索です。一致した行と語をハイライトし、タイトルが一致したページを先頭に並べます。
- 同じプロジェクトを複数のタブで開いていると、別のタブでの編集・作成・削除を自動で反映します（自分が入力中のページは上書きしません）。

## 記法

| 書き方 | 表示 |
|---|---|
| `[* 太字]` `[** 大きく]` `[/ 斜体]` `[- 取り消し線]` `[_ 下線]` `[~ 薄く]` | 文字装飾（組み合わせ可：`[*/ 太字の斜体]`） |
| `[[太字]]` | 太字 |
| `[ページ名]` `#タグ` `[ページ名#L3]` | ページ・行へのリンク |
| `[/プロジェクト名/ページ名]` | 別プロジェクトのページへのリンク |
| `[ページ名.icon]` `[ページ名.icon*3]` | そのページの最初の画像を丸いアイコンで表示（画像が無ければ頭文字）。数字で個数を指定 |
| `https://example.com` | 本文中のURLは自動でリンク |
| `[https://example.com ラベル]` `[ラベル https://example.com]` | ラベル付きリンク |
| `[https://例.com/画像.png]` `[/uploads/…png]` | 画像 |
| `[https://link.example https://例.com/画像.png]`（順序は逆でも可） | リンク付き画像 |
| `[** [https://例.com/画像.png]]` | 画像を大きく表示（`*` が多いほど大きい。ふだんはサムネイル）。画像をクリックすると拡大表示し、「−／＋」で大きさを変えられます。1行に複数書くと横に並びます |
| `[https://gyazo.com/…]` | Gyazoの画像を表示 |
| `[$ E = mc^2]` | 数式（TeX。KaTeXを同梱しているためオフラインでも表示） |
| `[https://youtu.be/…]` `[https://www.youtube.com/watch?v=…]` | YouTube。「再生」を押したときだけ埋め込みを読み込みます |
| `` `code` `` | インラインコード |
| `code:ファイル名.拡張子` ＋インデントした行 | コードブロック。拡張子から色分け（JS/TS・Python・シェル・Ruby・Go・Rust・C系・Java・SQL・JSON・YAML・HTML/XML・CSS ほか）し、ヘッダーからコピーできます |
| `table:名前` ＋タブ区切りの行 | テーブル |
| `>` | 引用 |

## プロジェクト

ページはプロジェクトごとに分かれます。左上のメニューで切り替え・作成でき、名前の変更や削除はプロジェクト設定から行います（最後の1つは削除できません）。最後に開いたプロジェクトを覚えています。

- 既存のデータは、初回起動時に自動で最初のプロジェクトへ移行します。移行前の完全なバックアップを `data/backup-before-v2-日時.sqlite` に残します。
- 移行前に、大文字小文字だけが違うタイトルが複数あった場合は、後のページの末尾に ` (2)` を付けて両方残します。

## UserCSS / UserScript

プロジェクト設定で、プロジェクトごとに次を設定できます。

- **カスタムCSS**：ページ全体に適用されます。
- **UserScript**：有効にすると、このプロジェクトを開くたびに実行されます。自分で書いた、または内容を理解したものだけを入れてください（画面内で任意のコードが動きます）。`scrapbox.Page.title` / `scrapbox.Page.lines` / `scrapbox.Project.name` / `scrapbox.Project.pages` / `scrapbox.PageMenu.addItem({title, onClick})` / `scrapbox.on('page:changed' | 'lines:changed', fn)` が使えます。Scrapbox本体の全APIとの互換はありません。

## 保存とバックアップ

入力から約650msで保存します（Macアプリ版は `~/Documents/scrapbox` の .txt ファイル、それ以外は `data/scrapbox.sqlite`）。保存状態は左下で確認できます。保存途中のブラウザ終了に備え、下書きもブラウザに一時保存します。複数タブから古い内容で上書きしようとした場合は、競合を表示して保存を止めます。

- 全データのバックアップ：Macアプリ版は `~/Documents/scrapbox`（メモと画像）をコピーすれば十分です。履歴も残すなら `~/Library/Application Support/Local Scrapbox/data` も。それ以外は、停止して `data/` フォルダ全体をコピーします。
- ほかのアプリで編集中に、アプリ側でも同じページを保存した場合は、上書きせずに相手の版を「（競合 日時）」付きの別ファイルとして残します。
- 画像込みの持ち運び：左上メニューの「JSONを書き出す（画像を含む）」。ページと、ページから参照している画像の実データを1つのJSONにまとめます。同じ形式のJSONを読み込むと画像も復元します。
- テキスト中心の移行：「JSONを書き出す」。Scrapbox互換の `pages[].lines` 形式です。
- JSON読み込み時は同名ページ（大文字小文字違いを含む）をスキップし、既存内容を上書きしません。ページの作成・更新日時（Scrapboxの `created` / `updated`）は保持します。
- Scrapboxから持ってきたページの画像（scrapbox.io・Gyazo）は、`bash ~/Documents/開発/local-scrapbox/macos/fetch-images.sh` で手元にダウンロードして差し替えられます（Macアプリ版）。非公開のプロジェクトは、ScrapboxのログインCookie（connect.sid）を聞かれます。入力は画面に出ず、保存もしません。
- 編集履歴は自動保存のたびに残ります。画面には新しい順に100件表示します。
- データフォルダを移したい場合は `SCRAPBOX_DATA_DIR`、ポートを変える場合は `PORT`、メモをファイルとして保存するフォルダは `SCRAPBOX_NOTES_DIR`、画像の保存先は `SCRAPBOX_UPLOADS_DIR` で設定できます。

## サーバーで動かす

パスワードを設定したときだけ、`127.0.0.1` 以外での公開ができます。パスワードが無いまま外部に公開する設定では、起動を拒否します。

```sh
SCRAPBOX_DATA_DIR=/var/lib/local-scrapbox node set-password.mjs   # パスワード設定（12文字以上）
HOST=127.0.0.1 PORT=3210 ALLOWED_HOSTS=notes.example.com TRUST_PROXY=1 node server.mjs
```

- ログインは、署名付きCookie（HttpOnly・SameSite=Strict、HTTPS時はSecure、30日）で保持します。パスワードを変えると全員ログアウトします。
- ログインの失敗はIPごとに回数を制限します。パスワードは `data/auth.json` にscryptのハッシュで保存します。
- `ALLOWED_HOSTS` 以外のドメインからのアクセスは拒否します。Nginx・HTTPS・systemd・バックアップまでの手順は [deploy/README.md](deploy/README.md) にあります。

## 実装範囲

Scrapbox / Cosenseの公式製品ではなく、独立したローカル実装です。公開画面を参考にした再現であり、全機能や全操作の完全互換ではありません。

**意図的に対応しないもの**：複数アカウント、クラウド同期、複数人での共同編集は、1人用のノートであるため実装しません（サーバーに置く場合のパスワードは1つだけです）（代わりに、同じMacの複数タブ間は自動で同期します）。行ごとの更新者表示も、1人用のため意味がなく対応しません。Mermaidは、Scrapbox本体にも標準では無いため対応しません。

**制限**：外部サービスの埋め込みはYouTubeのみです（Twitter/X・Spotify・地図などは通常のリンクとして表示）。行リンクは、Scrapboxのような不変の行IDではなく行番号です。同じページを複数のタブで同時に編集して競合した場合は、自動マージせず、保存を止めて知らせます。プロジェクト間のページ移動、プロジェクトごとの画像の分離はありません（画像は全プロジェクトで共有します）。公開済みノートの内容や公式ロゴは同梱していません。サンプルノートはこのアプリ用に作成しています。

通常の起動は `127.0.0.1` に限定します（サーバーで動かす場合は次の節）。ブラウザから外部サービスへノート内容を送信しません。ページ内に外部画像のURL・Gyazo・YouTubeなどを記入した場合は、表示時（YouTubeは「再生」を押した時）にそのサービスへアクセスします。数式ライブラリ（KaTeX、MITライセンス）は `public/vendor/katex/` に同梱しています。

## 検証

```sh
npm run check
npm test
```

テストは一時データベースを使い、実際のノートには触れません。保存・再起動・競合・名前変更・履歴・ゴミ箱・入出力・画像・入力エスケープ・プロジェクト・旧データベースの移行・タブ間通知・他サイトからのアクセス拒否・ログイン・記法の描画・バックアップ・ファイル保存（ほかのアプリでの編集・名前変更・削除・競合）を検証します。
